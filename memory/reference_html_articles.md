The global CLAUDE.md's "Prefer self-contained HTML over markdown for any document deliverable" bullet (under `## Communication`) is grounded in Thariq Shihipar's article and its companion examples site.

- Article (X.com, paywalled to anonymous fetchers): https://x.com/trq212/status/2052809885763747935 — "Using Claude Code: The Unreasonable Effectiveness of HTML"
- Simon Willison's summary (more reliably fetchable): https://simonwillison.net/2026/May/8/unreasonable-effectiveness-of-html/
- 20 self-contained HTML examples by category (the canonical pattern reference): https://thariqs.github.io/html-effectiveness/

Use these when the user asks for the rationale behind the preference, or when designing a new document deliverable and you need to recall what "Thariq-style HTML" actually looks like in practice.
